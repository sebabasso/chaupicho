# Chaupicho

Un mercado de cosas usadas entre amigos. Se entra solo por invitación, cada anuncio muestra a cuántos pasos está quien vende y todo se arregla por WhatsApp.

- Frontend: HTML, CSS y JavaScript sin build (`index.html`, `app.js`, `styles.css`), publicado en GitHub Pages.
- Backend: Supabase (proyecto `chaupicho`): perfiles, invitaciones, anuncios, categorías, fotos y las funciones `degrees()` y `chain_to()` para la cadena de invitaciones.
